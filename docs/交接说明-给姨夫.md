## 1. 这是什么

**OpenMemo** = AI 语音助手 + 任务/提醒管家，跑在**家里的 Mac mini** 上，语音交互为主（另有 iOS App 可装到 iPhone 上使用）。

- **服务端**：Python + FastAPI（`openmemo/`），端口 **18890**

## 2. 已完成的功能（现状）

### 🧠 AI 对话（核心，v1.0+）
- AI **全自主对话**：像真人一样聊天、追问、确认，AI 自己决定问什么、做什么
- 架构（Ethan 定的最终方案，**务必保持**）：**AI 负责一切"思考"与"说话"**；服务端只有**一个轻量程序**——解析 AI 输出的 JSON（`{action, reply, task, appointment…}`）→ 存任务 → 到点把 AI 写的提醒原文念出来。**没有任何模板、槽位填充、意图路由、拒绝清单**
- ⚠️ **铁律：不要加回任何"确定性对话代码"**——历史上每次加都会导致幻觉/死循环。出 bug 时**先改 SYSTEM_PROMPT（给 AI 更多指引），而不是加代码**
- 周期性任务复用同一 task_id，不产生重复行

### 🗣️ 语音与说话人（v1.1）
- **说话人识别（SI）**：App 内 6 步登记（输名字→3 次录音→Create ML 就地训练），自动识别谁在说话，消息路由到 `speaker_<名字>` 专属会话，**每个人的聊天/任务互相隔离（隐私不串台）**
- 未识别的人 = 访客：不泄露任何已登记用户的信息

### 😊 情绪与声音事件（v1.2，2026-08-31）
- **本地情绪识别**：sherpa-onnx + SenseVoice，完全离线，识别 高兴/悲伤/生气/恐惧/惊讶/中性
- 情绪注入 AI 上下文：AI 会直接说"你听起来有点生气"并调整语气
- **声音事件**：笑声/哭声/咳嗽/掌声——AI 会接梗、安慰、关心
- **反讽识别**：庆祝文字 + 悲伤声音 → 直接点破"这话像反话"
- 气泡说话人旁显示**情绪彩色标签**（高兴绿/悲伤蓝/生气红/恐惧紫/惊讶橙/中性灰）
- 情绪/说话人/声音事件已**落库**（messages 表 emotion/event/speaker 列），翻历史记录仍在
- 本地离线中文 STT：`POST /api/stt`（WAV→文本），做浏览器兜底

### 📝 任务/提醒体系
- 自然语言记任务；出行任务（赶飞机/高铁）会反推出发提醒；循环任务；带日程的重复任务（如暑假作业逐日分配）
- 到点 **Edge TTS 中文朗读提醒** + iOS **本地通知**
- 看护告警（watchdog）+ 提醒送达记录，App 轮询展示

### 🔐 隐私与稳定性
- 侧边栏只显示干净标签（"Ethan 的聊天"），永不显示消息内容
- 任务/提醒/告警按说话人隔离（跨用户 403）；AI 上下文不泄露他人任务
- 大量崩溃修复（录音引擎、时间戳视图越界、Catalyst 麦克风等），当前稳定

### 🎨 App UI
- 暗色极光玻璃拟态（App 默认设计）；聊天 5 分钟时间戳 → 已改为**跨天/暂停 ≥30 分钟才显示**（去 clutter）

## 4. 怎么跑 / 怎么维护

```bash
cd /Users/Ethan/Desktop/Projects/OpenMemo
# 启动（后台）
nohup .venv/bin/python -u -m openmemo.server > /tmp/openmemo_server.log 2>&1 &
# 健康检查
curl -s http://127.0.0.1:18890/api/health   # {"status":"running",...}
```

### ⚠️ 运维大坑（都踩过，务必记住）
1. **项目在 ~/Desktop 下时，绝不要用 launchd 自启**：macOS TCC 会拦 launchd 读 Desktop，Python 直接挂死在初始化（无弹窗可点）。真机持久化 = 把项目移出 Desktop（如 `~/Projects/OpenMemo`），或给 launchd 全盘访问权限（需 GUI）。**从普通 shell 启动没问题**
2. **不要 `pkill -f "openmemo.server"`**：会匹配到自己的命令行把会话杀了。停服务用 `kill $(lsof -tiTCP:18890 -sTCP:LISTEN)`（注意加 `-sTCP:LISTEN`，否则会杀到 App 的客户端连接）
3. 服务偶尔会死（exec 会话清理等原因），死了就按上面命令重启
4. Git 推送 GitHub **必须走本地代理**：`git -c http.proxy=http://127.0.0.1:7897 push origin main`（直连会超时）
5. macOS 没有 `timeout` 命令
