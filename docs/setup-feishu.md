# 飞书机器人接入指南（Step by Step）

OpenMemo 通过**飞书开放平台**接入，用户可以直接给飞书机器人发文字/语音消息。

---

## 1. 注册飞书开放平台应用

1. 打开 [飞书开放平台](https://open.feishu.cn/)（用管理员账号登录）。
2. 右上角 **创建企业自建应用**（如果你在某个企业/团队里）或选择自助开发。
3. 填写应用名称（如 "OpenMemo 助手"）和图标，创建完成。

## 2. 获取应用凭据（App ID / Secret）

进入你的应用 → **凭证与基础信息**：
- 复制 **App ID**（形如 `cli_xxxxxxxx`）→ 填入 `.env` 的 `FEISHU_APP_ID`
- 生成/复制 **App Secret** → 填入 `FEISHU_APP_SECRET`

## 3. 开启机器人能力

左侧菜单 **添加应用能力 → 机器人** → 点击启用。

## 4. 配置事件订阅（关键）

左侧 **事件与回调 → 事件配置**：

1. **请求地址 URL**：填
   ```
   https://你的隧道地址/webhook/feishu
   ```
   （隧道地址由 `cloudflared tunnel --url http://localhost:18890` 生成，见 README）

2. 开启 **加密策略**：勾选"使用加密"，把 `Encrypt Key` 复制到 `.env` 的 `FEISHU_ENCRYPT_KEY`。

3. 添加 **事件**，勾选：
   - `接收消息`（`im.message.receive_v1`）— 这是接收用户消息的必需事件
   - 其他按需添加

4. 会要求填写 **请求地址验证**：OpenMemo 服务端已内置 challenge 校验，点"保存"即可通过验证。

> ⚠️ 事件订阅 URL 必须能被公网访问。本地开发用 Cloudflare 快速隧道；生产建议用固定域名。

## 5. 配置权限（机器人发消息给用户）

左侧 **权限管理**，搜索并开通：
- `im:message`（读取发给机器人的消息）
- `im:message:send_as_bot`（机器人主动发消息，用于提醒推送）

发布版本后，需要**管理员审核通过**权限才生效。

## 6. 开放机器人给自己的用户

左侧 **版本管理与发布** → 创建版本并申请发布，审核通过后，你的用户就可以：
- 在飞书里搜索到你创建的机器人 **添加会话**
- 在私聊 / 群聊里 @机器人 或直接发消息

## 7. 把"接收提醒的用户"告诉 OpenMemo

在 `.env` 里填：
```
FEISHU_DEFAULT_USER=<接收提醒的用户的 open_id>
```
获取 open_id：让该用户在飞书给机器人发任意一条消息，然后在服务日志（`/private/tmp/openmemo.log` 或终端）里能看到该用户的 `open_id`。

## 8. 重启并测试

```bash
./start.sh
# 或：.venv/bin/python -u -m openmemo.server
```

在飞书给机器人发：
```
你好
```
应收到中文回应。再试试：
```
明天下午3点开会
```
到点会收到提醒推送。

## 常见问题

**Q：飞书收不到机器人回复 / 收不到提醒？**
- 确认隧道地址在 `.env` 的飞书后台请求地址是同一个（隧道重启会变）。
- 确认应用已发布且权限已审核通过。
- 确认 `FEISHU_DEFAULT_USER` 填了正确的 open_id。

**Q：事件订阅验证失败？**
- 确认服务已启动且能被公网访问（浏览器打开 `https://隧道地址/api/health` 应返回 `{"status":"ok"}`）。
- 确认 `FEISHU_VERIFICATION_TOKEN`、`FEISHU_ENCRYPT_KEY` 已正确填入 `.env` 并重启。

**Q：要用自己的企业飞书还是个人？**
- 个人体验可建一个"测试企业"应用；生产给客户用需在企业内发布或上线应用商店。
